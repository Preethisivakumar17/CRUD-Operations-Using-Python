# Student Management System

A simple Python-based Student Management System that performs CRUD operations using file handling.

## Features
- Add Student
- View Students
- Search Student
- Update Student
- Delete Student

## Technologies Used
- Python
- File Handling

## How to Run

1. Clone the repository
2. Open the project folder
3. Run:

```bash
python main.py
```

## Sample Data Format

Name,Age,Department

Example:
Priya,5,UKG
Arun,21,CSE
